2. Guided Code Tour

Key stops in the codebase that power this journey:

Stop 1: Test Builder Modal UI

frontend/src/components/TestBuilderModal.tsx

Renders the interactive test configuration dialog where learners choose between Objective and Subjective tests, configure question counts, difficulty sliders, and select specific extracted topics.

Stop 2: LLM Generation & Rubric Pipeline

backend/app/services/ai_service.py

Constructs system prompts with strict JSON schemas for Groq / OpenAI. Formulates the prompt based on material chunks, ensures all MCQs have 4 distinct options, and provides detailed rationale for every answer.

Stop 3: Test Creation & Submission Endpoints

backend/app/routers/tests.py

Handles authenticated routes POST /api/tests/generate and POST /api/tests/{id}/submit. Manages transaction isolation in PostgreSQL and delegates grading to the evaluation engine.

Stop 4: Diagnostic Results & Feedback Screen

frontend/src/app/results/[id]/page.tsx

Displays the completed attempt card with circular score meter, time taken, strengths breakdown, and question-by-question comparative feedback against ideal answers.

3. "To Change This, Start Here" Reference Pointers

Modify Question Generation Prompt backend/app/services/ai_service.py

Update generate_test_questions() to tweak question formats, difficulty prompts, or instructions.

Add Document Formats (e.g. TXT/EPUB) backend/app/services/document_parser.py

Add text extraction handlers for new file types during upload.

Adjust Brand Colors & Theme frontend/tailwind.config.ts

Tune primary emerald accents or dark zinc surface hex tokens.

JWT Authentication Rules backend/app/dependencies.py

Configure Supabase JWKS verification and asymmetric token decoding.

4. A Practice to Reuse

Schema-Enforced LLM Responses with Automated Verification

Instead of asking the LLM for unstructured free-text answers and hoping regex can parse it, ExamLoop enforces strict Pydantic v2 schemas and JSON mode. This eliminates hallucinations in grading, prevents API breakages, and ensures UI components always receive reliable, typed data structures.

How to run locally:
Backend: uvicorn app.main:app --reload --port 8000
Frontend: npm run dev (runs on port 3000)
